# Créditos das imagens

As faces das cartas dos temas `animais` e `objetos` são do **OpenMoji**
(https://openmoji.org), projeto aberto da HfG Schwäbisch Gmünd,
licenciadas sob **CC BY-SA 4.0** (https://creativecommons.org/licenses/by-sa/4.0/).
Foram redimensionadas para 256x256 px.

Os versos das cartas (`back.png`) foram gerados para este projeto.

Obs.: a licença CC BY-SA exige dar crédito (este arquivo) e que as imagens
adaptadas sejam distribuídas sob a mesma licença. Para uso pessoal não há
nenhuma obrigação adicional.
